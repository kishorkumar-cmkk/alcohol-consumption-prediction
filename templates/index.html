MODEL PERFORMANCE

Why Linear Regression?

Multiple regression algorithms were trained and evaluated. Hyperparameter tuning was performed on Random Forest and Gradient Boosting using cross-validation. Linear Regression achieved the highest R² score on the evaluation data and was therefore selected as the final deployment model.

Linear Regression 0.9468
Tuned Gradient Boosting 0.9377
Tuned Random Forest 0.8912
